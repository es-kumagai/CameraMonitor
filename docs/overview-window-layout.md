# 一覧ウィンドウの復元と左寄せ配置

## 要件と設計

カメラを一覧表示するウィンドウは、最後に保存したサイズと位置を次回起動時に復元する。保存情報がない場合は Storyboard の初期サイズを使う。個別カメラのウィンドウには変更を加えない。

`CameraCollectionWindow` は既存の AppKit フレーム保存名を引き続き使用する。起動時の移動・リサイズ通知が保存済みフレームを上書きしないよう、初期復元が終わるまで保存を抑止する。画面構成によるフレーム調整は AppKit に委ねる。

カメラ一覧は `LeftAlignedCameraCollectionViewFlowLayout` を使う。標準フローレイアウトの折り返しと縦位置を維持し、各行の項目を左余白から一定間隔で配置する。既存の項目サイズ 300 × 180 pt、余白と間隔 4 pt を維持する。表示領域の一部だけが問い合わせられた場合も、項目単体の問い合わせと同じ座標を返す。
